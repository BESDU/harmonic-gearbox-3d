# harmonic-gearbox-3d
harmonic-gearbox
Hi I'm making a 3D printed harmonic gearbox for my 6 axis manipulator project.
I've already made a simple model to check if it will work.
<img width="400" height="532" alt="IMG_6987" src="https://github.com/user-attachments/assets/da64544a-2af7-40e6-8421-b509d6b69884" />
It will work with nema 23 stepper motor and it will have reduction ratio 20:1.
